FeatureCards

Variants: emerald, colorful, gold

How it works: The FeatureCard is a square, clickable button designed for navigation or triggering major actions (like opening the Raffle or inviting friends). The entire card acts as a touch target. The name of the feature sits cleanly in a green bottom section, making it easy to read. Click the cards above to see their animation!

TaskCards

For missions and earning actions

How it works: The TaskCard is used for listing missions (like joining a channel or watching a video). It supports three visual states:

1. Pending: Displays a yellow "Go" button to start the task.
2. Checking: The user has clicked the task but needs to verify it. Shows a grey "Go" button (in case they need to return to the task) and a cyan "Check" button to verify completion.
3. Completed: The entire card dims slightly and the button becomes a grey, disabled "Done" button.

Task Banners

Thin entry points for the home page

How it works: The TaskBanner is a slimmer version of the TaskCard, meant to be placed on the Home page to encourage users to enter the full task section. It uses the exact same color variables as the TaskCard to maintain consistency.
